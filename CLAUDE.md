# Motor Teknika website
Stack: Next.js (App Router, TypeScript) + Tailwind CSS. Deploy on Vercel.
Design: dark, orange accent. Font: Inter (next/font).
Colors: bg #07090D, panel #0E1219, border #222A36 (name it "line"),
text #F4F5F7, muted #99A2B0, orange #FF6A13, green #35D07F.
Rules:
- Mobile first. Check 390, 768 and 1440 widths.
- Server components by default. Use "use client" only where needed.
- Reusable components in src/components, content in src/data.
- Use next/image for images. Keep text accessible (alt text, focus states).
- Build only what I ask for in each prompt. No extra pages or features.
Pages: Home, Services, How It Works, About, Contact.
Reference images are in the reference folder. Device images are in public/devices.
